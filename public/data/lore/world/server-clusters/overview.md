# Server Clusters
The world of Xanrea is not a planet in the traditional sense, but a complex network of server clusters. These clusters manage the simulation of reality, physics, and soul persistence.

## Cluster Architecture
- **Core Cluster**: Manages the primary laws of physics and the "Admin" interface.
- **Regional Nodes**: Distributed clusters that handle specific geographic areas to reduce latency in soul-processing.
- **Persistence Layers**: Where the data for every NPC and Traveler is stored.

## The Server Logic
The "World" is essentially a series of layered simulations. When a Traveler enters, they are assigned to a specific node. The process of "death" is simply the server recycling a soul-vessel and moving the essence back to the queue for re-assignment.
